# CleanYourVizio

A Google Cast receiver page: a clean, Apple TV–style home screen for a Vizio SmartCast TV.

The page holds no data. A sender on the home network pushes the dock tiles, focus and weather
over the `urn:x-cast:com.cleanyourvizio.home` channel; the clock runs locally. Inspired by
[cleanyourtv](https://github.com/Gathin23/cleanyourtv).
